Backup & Restore

Your quotes, prices, rates, customers and settings are saved only in this browser, on this computer. They don't sync, and clearing your browsing data erases them. Export a backup file regularly and keep it somewhere safe (cloud drive or email) — and use it to move everything to another computer.

The backup file does not include your AI API key, so it's safe to store and share within your shop.

AI Connection
Required for AI drawing extraction. Two ways to connect — the Proxy method is more secure for a hosted/shared tool.
★ Recommended: AI Proxy URL
Your API key lives on a server (Cloudflare Worker), never in the browser. Paste your Worker URL here. When set, this is used instead of the key below. See the setup guide for the one-time 10-minute setup.
Alternative: Direct API Key
Key saved in this browser only. Simpler, but the key is readable by anyone with access to this computer's browser. Only used if no Proxy URL is set above.
Shop Info
Smallest amount of a sheet billed per order. Prevents tiny-qty parts that nest many-per-sheet from being undercharged, but keeps the charge fair.

Default Quote Assumptions

Time Standards (min/part)

Default minutes per part auto-filled when you select an operation. Based on your actual shop times — tune these as you track real run times. Leave blank to require manual entry.

Changelog

Version history and updates to the BSMP Quote Tool

v1.0.0 Current June 2026
Print assembly quotes
  • New Print quote button on the New Assembly Quote screen — prints/saves a PDF in the exact same format as a regular customer quote
  • The assembly's job name is used as the part number on the quote, with the component parts listed beneath it
  • Order qty, price per assembly, and job total carry over; you can still set bill-to, ship-to, quote #, date, lead time, and assumptions before printing
Nesting fix — parts per sheet now checks both orientations
  • Fixed the sheet-count being too high: the parts-per-sheet calc only tried one part orientation, so parts that nest better rotated were undercounted (e.g. a 24×42 on a 48×120 read 2/sheet instead of 4)
  • It now tests the part as-entered and rotated 90° and uses whichever fits more, so the result no longer depends on which dimension you type as height vs length
  • Applies to both the main quote and the quantity-break schedule, lowering over-stated material and sheet counts
Storage fix — saving no longer fails when full
  • Fixed the bug where saving silently did nothing (no confirmation) once the browser's storage filled up
  • Drawing previews are now stored as small compressed thumbnails instead of full-size images — roughly 95% smaller, so you can save far more quotes before hitting any limit
  • Existing saved quotes are automatically shrunk once on load to reclaim space
  • If storage ever does fill, saving now recovers automatically (trims the oldest previews first) and tells you what happened instead of failing quietly — back up and clear old quotes when you see that warning
Backup & Restore
  • Export a full backup of your data to a dated .json file — quotes, archived quotes, material prices, rates, customers, tier markups, and shop settings
  • Restore from a backup file with a choice of Merge (adds without duplicates, keeps current settings) or Replace all (exact restore)
  • Use it to recover after clearing browser data, or to move everything to another computer
  • Backups never include your API key, so the file is safe to store and share
  • Export from Settings → Backup & Restore, or the quick ⤓ Backup button on the Quote History toolbar
  • Reminder: browser storage is per-computer and per-browser and is erased if you clear browsing data — back up regularly
CNC Mill Estimator
  • New CNC Mill card — prices billet material by volume instead of sheet nesting (fixes $0 material on machined parts)
  • CAM programming and machine setups captured as one-time costs, amortized over the order quantity
  • Run/cycle time per part at a chosen mill rate code, plus tooling/consumables allowance
  • Number of setups/ops field — handles multi-op parts (e.g. flip to machine the back)
  • Optional cycle-time estimator: roughing from material-removal rate + hole/feature counts, applied to the run-time field
  • Stock forms: plate/block, round billet, or customer-furnished (free)
  • Flows through the same markup, finance, and quantity logic as the rest of the quote
  • Shows clearly why low-qty machined parts are expensive: programming + setup + first-article dominate at qty 1–2 and amortize away at volume
  • Worked example pre-loaded: ResMed NEST, PLATE (6061, tight-tolerance, 2-op)
Welding Estimator
  • New Welding card on the quote — runs standalone for welding-only jobs or adds to a fab quote
  • Weld time computed from joint geometry: process, joint type, size, length, weld count, and position
  • Deposited weight and arc time derived from weld cross-section × length × passes, derated for out-of-position welding
  • Process library: TIG/GTAW, MIG/GMAW, flux-core/FCAW, stick/SMAW with deposition rates and efficiencies
  • Arc-on (operating) factor converts arc time to real labor hours
  • Consumables: filler wire/rod by the pound and shielding gas by arc-hour
  • Prep & finishing: fit-up/tack, interpass cleaning, grind/blend minutes
  • Post-weld services: NDT (VT/PT/MT/RT), heat treat (stress relieve/normalize), finish/plating, marking, and cert/inspection docs
  • All welding cost flows through the same markup, finance, and quantity logic as the rest of the quote
  • Worked example pre-loaded: H-60 Cargo Hook tie-down weldment (AWS D17.1 Class A)

  • All 50+ process rate codes with $/hr rates

  • Customer list with per-customer markup and finance rates

  • Auto-populates all 4 process steps from drawing process table

  • Sheets needed metric card with parts/sheet and material total

  • 3 decimal place precision on run time inputs
Batch Operations

  • Both calculators auto-update operation run time fields

  • Quantity breaks recalculate batch time correctly at each qty level
